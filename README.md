# APK 伪装器

APK 伪装器是一款 Android 应用。它通过应用宝接口搜索应用，在本机生成使用所选应用名称和包名的空壳 APK，并交由系统安装器确认。空壳内置离线人机井字棋。

## 使用方式

先下载 APK 并安装到支持 ARM64 的 Android 7.0 或更新设备。

### 主应用

1. 打开 APK 伪装器，在搜索框输入应用名称或关键词。
2. 在结果中找到目标应用，点击「安装」。首次安装空壳时，按系统提示允许 APK 伪装器安装未知应用，然后在系统安装器中确认。
3. 安装完成后，可从桌面或主应用的「安装记录」打开空壳。也可以在安装记录中卸载，或点击空壳标题栏右侧的「卸载」。

### 悬浮搜索

在主应用右上角点「打开悬浮按钮」，首次开启时按提示授予悬浮窗权限。之后可在其他应用页面拖动悬浮按钮，点击它打开搜索窗口，直接搜索并安装空壳。需要隐藏按钮时，在主应用右上角点「关闭悬浮搜索」。

### 系统栏快捷按钮

下拉系统控制中心，进入快捷设置的编辑页面，将「APK 伪装器」添加到快捷按钮列表。之后点击该按钮，即可收起控制中心并直接打开搜索窗口。

### Root 模式

1. 在已有 Root 的设备上打开右上角「设置」，开启「Root 模式自动安装」，然后在 Root 管理器中选择「允许」。开关默认关闭，授权成功后会保存开启状态。应用启动时不会请求 Root。
2. 在搜索结果中点击「安装」，应用会在后台生成、签名并安装空壳。安装成功后，可在「安装记录」查看。
3. 在搜索结果或「安装记录」中点击「卸载」。核对确认弹窗里的应用名称和包名，再点「卸载」。

未获得 Root 授权时，安装和卸载会交给 Android 系统界面确认。
